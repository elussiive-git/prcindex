# Архитектура

React + TypeScript развёртывается как статический сайт на Cloudflare Pages. Supabase даёт PostgreSQL, Auth и закрытый Storage. В браузер попадают только публичные URL проекта и anon key; service-role key используется исключительно локальными административными скриптами/CI и не коммитится.

Статистика вынесена в `src/stats.ts`. Для корпуса из 492 записей загрузка Pyodide + SciPy тяжелее, чем расчёты на TypeScript; поэтому первая версия выполняет частоты, χ², V Крамера и Holm непосредственно в Web Worker/клиенте, а эталонный импорт сохраняет исторические результаты SciPy 1.16.3. Монте-Карло и Фишер должны быть добавлены в отдельный Worker перед публикацией аналитического режима; сохранённый запуск всегда содержит corpus, method, program version, parameters, seed, frequency tables и results.

Миграции разделяют компании, неизменяемые версии файлов, версии методики, разметку, зафиксированный корпус и запуск анализа. RLS проверяет роль, отзыв и `access_expires_at` при каждом запросе. Storage закрыт; тестировщик загружает только в собственный префикс и не утверждает корпус.
