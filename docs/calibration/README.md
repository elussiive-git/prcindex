# Калибровка методики v1.0

Запуск: `node scripts/calibrate-methodology.mjs`.

Скрипт воспроизводимо отбирает 50 логотипов с seed `20261117`, создаёт два одинаковых слепых файла `coder-a.csv` и `coder-b.csv`, сравнивает цветовые пороги 5%, 8%, 10% и 15% по всему корпусу и пишет результат в `report.json`.

Расчёт порогов пока является прототипом: автоматическое преобразование HEX в 12 цветовых семей должно сначала воспроизвести текущую разметку при пороге 8%. Пока в `thresholdModel.status` стоит `prototype-needs-color-family-calibration`, числовые результаты чувствительности нельзя использовать как окончательный вывод.

Кодировщики заполняют только столбцы `color`, `hex`, `sign_type`, `motif`, `borderline` и `comment`. Они не должны видеть `sample-manifest.json` до завершения разметки. После заполнения обоих CSV повторный запуск рассчитает α Криппендорфа отдельно для цвета, типа знака и образа.

`sample-manifest.json` содержит исходную авторскую разметку только для последующей сверки и должен оставаться скрытым от кодировщиков.
