# Методика цвета v2.0 (черновик)

Цвет измеряется детерминированным алгоритмом: `scripts/color-scan/scan_colors.py`. Тот же файл с теми же параметрами всегда даёт тот же результат. Нейросеть цвет не определяет. Все пороги лежат в `PARAMS` и сохраняются вместе с каждым прогоном (`params_hash`).

## Единица анализа
1 компания · 1 официальная версия логотипа (позитив; SVG, если есть). Учитывается то, что видно в файле.

## Шаги
1. **Растеризация.** Длинная сторона 400 px; SVG рендерится через rsvg-convert с прозрачным фоном.
2. **Фон.**
   - Прозрачные пиксели — фон.
   - Если рамка изображения однородна (≥ 85% пикселей рамки ближе ΔE_OK 0,04 к её медиане):
     - светлая рамка (L ≥ 0,90, C < 0,05) — это фон. Цвет фона убирается везде, где встречается, включая просветы внутри букв;
     - тёмная или цветная рамка — это **плашка**. Она входит в цвет знака и помечается флагом.
   - Если рамка неоднородна (градиент, фото): при доле светлых пикселей ≥ 25% фоном считаются они, иначе фон не определён (флаг, ручная проверка).
3. **Очистка.** Не учитываются:
   - полупрозрачные пиксели и кольцо в 1 px вокруг фона (сглаживание краёв);
   - оттенки, которые лежат на отрезке между двумя более крупными цветами (промежуточные цвета на краях; проверяются цвета меньше 10% площади);
   - цвета меньше 1% площади знака.
4. **Цвета знака.** Оттенки объединяются в пространстве OKLab: ближе ΔE_OK 0,07 — один цвет, не больше 6 цветов. По каждому цвету сохраняются HEX, доля площади, L, C, h.
5. **Семья цвета** (12 семей, по OKLCH):
   - ахроматический, если C < 0,035 или (L < 0,25 и C < 0,05). Очень тёмные оттенки воспринимаются как чёрный. Дальше по светлоте: L < 0,40 чёрный, L ≥ 0,93 белый, остальное серый;
   - коричневый: h 30–100°, L 0,25–0,55, C < 0,14;
   - остальные по сектору оттенка: розовый 325–9,5°, красный 9,5–35°, оранжевый 35–82°, жёлтый 82–117,5°, зелёный 117,5–169°, бирюзовый 169–231°, синий 231–279°, фиолетовый 279–325°. Очень светлый красный (L ≥ 0,80) считается розовым.
   - Границы секторов откалиброваны по исторической ручной разметке 492 логотипов: каждая граница стоит там, где ручная разметка двух соседних семей расходится меньше всего.
6. **Переменные логотипа** (вычисляются, не вводятся вручную):
   - хроматичность — доля цветных пикселей знака;
   - статус: ахроматический (цветного < 8%) / ахроматический с акцентом / хроматический;
   - основная семья — наибольшая доля, включая чёрный;
   - ведущий хроматический цвет — наибольшая цветная семья, если цветного ≥ 8%;
   - цвет (сопоставимый с v1) — ведущий хроматический, иначе главная ахроматическая семья;
   - число семей и тип палитры; температура.
7. **Пограничные случаи** уходят в ручную проверку. Признаки:
   - цвет ≥ 8% площади с оттенком ближе 5° к границе сектора;
   - насыщенность в пределах ±0,012 от порога ахроматичности;
   - хроматичность 5–12%;
   - фон не определён;
   - низкое разрешение.

## Обоснование порога 8%
Порог операциональный, а не нормативный. Распределение хроматичности двугорбое: логотипы либо почти ч/б, либо почти целиком цветные. Порог стоит в провале между пиками. Проверка чувствительности (прогон v2, n = 492):

| Порог | Ахроматических |
|---|---|
| 3% | 143 (29,1%) |
| 5% | 154 (31,3%) |
| **8%** | **164 (33,3%)** |
| 10% | 173 (35,2%) |
| 12% | 179 (36,4%) |
| 15% | 184 (37,4%) |
