# Бесплатное размещение и ограничения

Проверено 17.11.2026 по официальным страницам тарифов.

## Supabase Free

- 2 активных бесплатных проекта; проект может приостанавливаться после недели низкой активности.
- PostgreSQL: 500 МБ данных на проект (диск Free фиксированного размера 2 ГБ).
- Storage: 1 ГБ; максимальная загрузка 50 МБ (приложение намеренно ограничивает логотип до 10 МБ).
- 50 000 MAU, 5 ГБ обычного и 5 ГБ кешированного egress.
- Автоматические резервные копии не включены: нужен регулярный ручной экспорт `pg_dump` + Storage manifest.

Для 492 небольших логотипов вариант пригоден, если исходники с превью помещаются в 1 ГБ. Перед импортом скрипт должен вывести суммарный размер; при приближении к 800 МБ нужно уменьшать только превью, не оригиналы, либо переносить хранилище.

## Cloudflare Pages Free

- 500 сборок в месяц, одна одновременная сборка, тайм-аут 20 минут.
- До 20 000 файлов на сайт, не более 25 MiB на отдельный статический файл.
- Для этого проекта Pages хранит только сборку интерфейса; оригиналы логотипов остаются в private Supabase Storage.

## Обязательное действие владельца

Создать бесплатный Supabase project без платёжных данных и сообщить только Project URL и public anon key. Service-role key не передавать в браузер и не добавлять в репозиторий. Затем выполнить миграции, создать пользователя-владельца вручную и отключить открытую регистрацию. После этого создать Cloudflare Pages project с output `dist`.

Источники: https://supabase.com/pricing, https://supabase.com/docs/guides/platform/billing-on-supabase, https://developers.cloudflare.com/pages/platform/limits/
